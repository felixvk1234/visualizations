## Adding a new visualization

1. Create a folder under `viz/<your-viz-name>/` with its own `index.html` (+ `style.css`, `script.js`).
2. Add a card linking to it in the root [`index.html`](index.html).
3. Commit and push — GitHub Pages redeploys automatically.

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
