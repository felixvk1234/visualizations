How a neural network learns

A network learns by making a guess, measuring how wrong it was, and adjusting itself to make a slightly better guess next time. That adjustment process is backpropagation.

Show the math behind the basic learning loop

Make a prediction

$$ a^{(l)} = \sigma(W^{(l)}a^{(l-1)} + b^{(l)}) $$

Each layer combines incoming values using weights, adds a bias, then applies an activation function.

Measure the mistake

$$ L = \frac{1}{2}(\hat{y} - y)^2 $$

The loss is a single number describing how far the prediction is from the goal.

Adjust a weight

$$ W \leftarrow W - \alpha \frac{\partial L}{\partial W} $$

The gradient says which direction reduces the mistake; the learning rate controls the step size.

Show the math behind sequence learning

Update memory

$$ h_t = \tanh(W_{hh}h_{t-1} + W_{xh}x_t + b_h) $$

Make a prediction

$$ \hat{y}_t = \operatorname{sigmoid}(W_{hy}h_t + b_y) $$

Add sequence losses

$$ L = \sum_{t=1}^{T} L_t(y_t, \hat{y}_t) $$

The one idea to remember

Backpropagation assigns responsibility for a mistake.

A forward pass creates a prediction. Backpropagation works backward to estimate which adjustable connections caused the mistake. Training repeats this loop until predictions improve.
